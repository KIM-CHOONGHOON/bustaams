# 여행자용 예약 전체 취소 및 버스 교체 설계

본 문서는 '내 예약 목록' 화면에서 여행자가 여정 전체를 취소하거나, 이미 선택한 버스를 교체하기 위해 예약을 취소하는 로직에 대해 정의합니다.

## 1. 비즈니스 로직 개요
- **대상 화면**: 나의 예약 목록 (My Reservations)
- **주요 기능**: 
    1. **여정 전체 취소**: 여행 계획 자체가 취소되어 모든 입찰과 예약을 종료함.
    2. **버스 교체 (Bus Change)**: 이미 선택한 기사가 마음에 들지 않거나 조건이 바뀌어 다른 버스를 다시 찾기 위해 예약을 취소함.

## 2. 데이터베이스 업데이트 로직

### A. 여정 전체 취소 (Full Cancel)
- **TB_AUCTION_REQ**: `DATA_STAT` -> **'TRAVELER_CANCEL'**
- **목적**: 해당 경매 요청 건 자체를 완전히 종료 처리함.

### B. 버스 교체 (Bus Change)
- **TB_AUCTION_REQ**: `DATA_STAT` -> **'BUS_CHANGE'**
- **목적**: 기존 기사와의 관계는 정리하고, 다시 입찰을 받을 수 있는 상태로 전환 (또는 재등록 프로세스 진행).

### C. 공통 처리
- **TB_USER_CANCEL_MANAGE**: 해당 여행자의 전체 취소 횟수(`CANCEL_TRAVELER_ALL_CNT`) 등을 업데이트하여 페널티 관리.
