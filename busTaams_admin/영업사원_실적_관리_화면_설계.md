# 영업사원 실적 관리 화면 설계서

본 문서는 관리자 페이지의 **영업사원 실적 관리** 화면에 대한 명세 및 백업 문서입니다.

---

## 1. 화면 개요
- **메뉴명**: 영업사원 실적
- **목적**: 플랫폼에 등록된 영업사원(`ADMIN_GRADE = 'SALES'`)들의 드라이버 유치 실적과 매출(성사 수수료) 기여도를 조회하고 모니터링합니다.
- **주요 대상 테이블**: `TB_ADMIN`, `TB_USER`, `TB_BUS_RESERVATION`

---

## 2. 화면 구성 및 UI 설계

### 2.1. 상단 요약 카드 (Summary Cards)
- **총 기사 유치수**: 플랫폼 전체에 가입된 기사(`USER_TYPE = 'DRIVER'`) 중 영업사원 추천 코드로 가입한 총 기사 수.
- **총 매칭 성사 건수**: 유치한 기사들이 운행을 최종 매칭 및 완료한 총 건수.
- **총 플랫폼 수수료 수익**: 매칭이 완료되어 플랫폼에 발생한 수수료 총액.

### 2.2. 검색 필터 패널 (Search Panel)
- **사원 아이디**: 특정 영업사원 아이디로 필터링 (부분 일치 검색)
- **사원 이름**: 특정 영업사원 이름으로 필터링 (부분 일치 검색)
- **초기화 및 조회 버튼**

### 2.3. 영업사원 실적 집계 목록 (Master Table)
- **노출 대상**: `ADMIN_GRADE`가 `'SALES'`인 관리자 계정만 표시 (SUPER, MANAGER 제외)
- **표시 컬럼**:
  - 사원 아이디
  - 이름
  - 소속 부서
  - 권한 등급
  - 유치 기사 수
  - 매칭 성사 수
  - 총 거래액 (입찰가)
  - 총 수수료 수익
- **동작**: 특정 사원 행을 클릭하면 하단의 **상세 매칭 실적 내역** 테이블에 세부 정보가 조회됩니다.

### 2.4. 상세 매칭 실적 내역 (Detail Table)
- **노출 데이터**: 선택된 영업사원 추천 코드로 가입한 드라이버의 실제 매칭 운행 목록 (`TB_BUS_RESERVATION` 연계)
- **표시 컬럼**:
  - 예약 번호
  - 여행 제목
  - 버스 기사 (이름 및 아이디)
  - 매칭 고객 (여행자 이름)
  - 이동 경로 (출발지 읍면동 -> 목적지 읍면동)
  - 기사 낙찰가
  - 수수료 수익
  - 성사일자

---

## 3. 백엔드 API 명세

### 3.1. 영업사원별 실적 집계 API
- **Endpoint**: `GET /api/admin/sales-performance`
- **Description**: 전체 관리자 테이블(`TB_ADMIN`)에서 `ADMIN_GRADE = 'SALES'`인 계정만 필터링하여 드라이버 유치 및 성사 실적을 집계하여 반환합니다.
- **Response Structure** (JSON):
  ```json
  [
    {
      "adminId": "sales01",
      "adminName": "홍길동",
      "deptName": "영업1본부",
      "role": "SALES",
      "driverCount": 12,
      "matchCount": 8,
      "totalBidding": 9600000,
      "totalFee": 960000
    }
  ]
  ```

### 3.2. 사원별 상세 매칭 실적 API
- **Endpoint**: `GET /api/admin/my-performance`
- **Query Parameters**:
  - `adminId`: 조회할 영업사원 ID
- **Response Structure** (JSON):
  ```json
  [
    {
      "resId": "10023",
      "tripTitle": "서울-부산 워크숍",
      "driverName": "이몽룡",
      "driverUserId": "driver05",
      "travelerName": "성춘향",
      "startAddr": "서울시 강남구 역삼동",
      "endAddr": "부산시 해운대구 우동",
      "biddingPrice": 1200000,
      "feeTotalAmt": 120000,
      "confirmDt": "2026-05-20 14:30"
    }
  ]
  ```
