# 회원 관리 화면 설계서

본 문서는 관리자 페이지의 **회원 관리** 화면에 대한 명세 및 백업 문서입니다.

---

## 1. 화면 개요
- **메뉴명**: 회원 관리 (`members`)
- **목적**: 플랫폼에 등록된 여행객(일반 사용자) 및 버스 기사(공급자)의 회원 계정 정보를 조회하고 검색합니다. 특히 기사 회원의 경우 등록 차량 스펙과 평점 정보를 함께 노출하여 손쉬운 모니터링을 돕습니다.
- **주요 대상 테이블**: `TB_USER`, `TB_DRIVER_DETAIL`, `TB_BUS_DRIVER_VEHICLE`

---

## 2. 화면 구성 및 UI 설계

### 2.1. 탭 구성 (Tab Menu)
- **여행자 회원**: 일반 여행 예약 요청을 올리는 여행자 목록 조회.
- **버스 기사 회원**: 입찰 및 운행을 수행하는 기사 목록 조회.

### 2.2. 검색 필터 패널 (Search Panel)
- **검색 조건**: 전체 통합 검색, 사용자명, 아이디, 휴대폰 번호
- **초기화 및 조회 버튼**

### 2.3. 회원 목록 테이블 (Members Table)
- **공통 컬럼**:
  - 이름
  - 아이디 (로그인용)
  - 휴대폰 번호
  - 가입 일시
  - 회원 상태 (ACTIVE/BANNED/LEAVE/TEMPORARY)
- **여행자 전용 컬럼**:
  - 이메일
- **버스 기사 전용 컬럼**:
  - **버스 정보**: 차량번호, 버스 모델명, 서비스 등급 (Premium/Executive/Standard 등)
  - **평점 (리뷰수)**: 평균 평점(★ X.X) 및 누적 매칭 완료 리뷰 수

---

## 3. 백엔드 API 명세

### 3.1. 회원 목록 조회 API
- **Endpoint**: `GET /api/admin/members`
- **Query Parameters**:
  - `userType`: `TRAVELER` 또는 `DRIVER` (필수)
  - `searchType`: 검색 필터 조건 (`all`, `userNm`, `userId`, `hpNo`)
  - `searchKeyword`: 검색어
- **Response Structure (userType = 'DRIVER')**:
  ```json
  [
    {
      "custId": "CUST0000000000000001",
      "userId": "driver_kim",
      "userNm": "김기사",
      "hpNo": "010-1234-5678",
      "email": "driver1@test.com",
      "userType": "DRIVER",
      "userStat": "ACTIVE",
      "joinDt": "2026-05-20 10:15",
  ```
