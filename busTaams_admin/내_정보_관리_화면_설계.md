# 내 정보 관리 화면 설계서

본 문서는 관리자 페이지의 **내 정보 관리** 화면에 대한 명세 및 백업 문서입니다.

---

## 1. 화면 개요
- **메뉴명**: 내 정보 관리 (`my-info`)
- **목적**: 현재 로그인된 관리자 본인의 인적 사항(이름, 소속 부서, 휴대폰 번호, 이메일 주소)을 조회 및 수정하고, 보안 강화를 위한 비밀번호 변경 기능을 원스톱으로 제공합니다.
- **주요 대상 테이블**: `TB_ADMIN`

---

## 2. 화면 구성 및 UI 설계

### 2.1. 좌측 프로필 서머리 카드 (Profile Summary Card)
- **사용자 아바타**: 기본 사용자 아이콘 노출.
- **관리자명 및 ID**: 본인의 실명 및 계정 ID 노출 (ID는 수정 불가 고정).
- **보안 권한 등급**: `SUPER` (최고 관리자), `MANAGER` (일반 관리자), `SALES` (영업 담당자) 등 등급 라벨 표시.
- **기본 인적사항 요약**: 등록된 휴대폰 번호, 이메일 주소, 소속 부서 정보 요약 표시.

### 2.2. 개인 정보 수정 영역 (Edit Profile Info)
- **수정 가능 항목**:
  - **이름 (ADMIN_NM)**: 필수 항목.
  - **소속 부서 (DEPT_NM)**: 선택 항목.
  - **휴대폰 번호 (HP_NO)**: 선택 항목 (하이픈 없이 입력 권장).
  - **이메일 주소 (EMAIL)**: 선택 항목 (이메일 패턴 검증).
- **정보 수정 저장 버튼**: 클릭 시 `/api/admin/:adminId/status` API 호출 및 브라우저 로컬 스토리지(`adminUser`) 정보 동기화.

### 2.3. 비밀번호 변경 영역 (Edit Password)
- **입력 필드**:
  - **현재 비밀번호**: 본인 확인을 위해 기존 비밀번호를 입력받음.
  - **새 비밀번호**: 변경할 새 비밀번호 입력.
  - **새 비밀번호 확인**: 변경할 비밀번호의 유효성 검증을 위해 한 번 더 입력받음.
- **비밀번호 업데이트 버튼**: 클릭 시 `/api/admin/change-password` API 호출.
- **검증 규칙**:
  - 세 필드 모두 입력 필수.
  - 새 비밀번호와 새 비밀번호 확인이 정확히 일치해야 함.
  - 새 비밀번호는 현재 비밀번호와 동일할 수 없음.

---

## 3. 백엔드 API 명세

### 3.1. 개인 정보 수정 API
- **Endpoint**: `PATCH /api/admin/:adminId/status`
- **Request Body**:
  ```json
  {
    "adminNm": "홍길동",
    "deptNm": "개발팀",
    "hpNo": "01012345678",
    "email": "gildong@bustaams.com"
  }
  ```
- **Response Structure**:
  ```json
  {
    "message": "관리자 정보가 성공적으로 업데이트되었습니다."
  }
  ```

### 3.2. 비밀번호 변경 API
- **Endpoint**: `POST /api/admin/change-password`
- **Request Body**:
  ```json
  {
    "adminId": "admin123",
    "currentPassword": "tempPassword123",
    "newPassword": "newSecurePassword456"
  }
  ```
- **Response Structure**:
  ```json
  {
    "message": "비밀번호가 성공적으로 변경되었습니다."
  }
  ```
