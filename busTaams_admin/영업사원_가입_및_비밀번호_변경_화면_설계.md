# 영업사원 가입 화면 및 비밀번호 조건 변경 백업 명세서

- **작업 일시**: 2026-06-02
- **작업자**: Antigravity
- **관련 테이블**: `TB_ADMIN` (`BANK_NM`, `ACCT_NO` 컬럼)

## 변경 요구사항 요약
1. **비밀번호 강제 변경 조건 해제**: 영업사원(`SALES`) 등급 가입 시 첫 로그인 단계에서 강제 비밀번호 변경 프로세스를 제거하고, 발급받은 비밀번호(휴대폰 번호 뒤 4자리)로 바로 메인 화면 진입 가능토록 수정.
2. **환급 계좌 정보 수집**: 영업사원 가입 신청 및 내 정보 관리 수정 시 은행명(셀렉트 박스)과 계좌번호 입력을 필수 처리하여 수집.

## 소스 코드 백업 정보

### 1. 백엔드 서버 API 변경 사항
- **파일 경로**: `busTaams_server/routes/appAdmin.js`
  - **가입 API (`POST /signup`)**:
    - 가입 데이터 삽입 쿼리에 `BANK_NM` 및 `ACCT_NO` 매핑 추가.
    - 등급이 `SALES`인 경우 `PWD_CHG_DT`를 `NULL`이 아닌 `NOW()`로 즉시 설정하여 최초 로그인 시 비밀번호 변경 의무 조건 회피.
  - **로그인 API (`POST /login`)**:
    - 등급이 `SALES`인 경우 `requirePasswordChange` 판별식을 강제로 `false` 반환토록 세팅.
    - 로그인 응답 객체에 `bankNm`, `acctNo` 프로필 필드 포함.
  - **수정 API (`PATCH /:adminId/status`)**:
    - 업데이트 필드 리스트에 `bankNm` 및 `acctNo` 추가.
  - **목록 조회 API (`GET /list`)**:
    - `TB_ADMIN` 조회 시 `BANK_NM` 및 `ACCT_NO` 정보를 객체 형태로 추가 반환.

### 2. 어드민 프론트엔드 변경 사항
- **가입 화면 (`busTaams_admin/src/AdminSignup.jsx`)**:
  - 계정 구분에 `SALES` (영업사원) 옵션 추가.
  - `role === 'SALES'` 일 경우, 환급 은행명 선택 박스(국내 12개 은행 선택 지원) 및 계좌번호 입력창을 동적으로 활성화하고 필수 유효성 검사 적용.
- **사용자 관리 모달 및 폼 (`busTaams_admin/src/pages/UsersManagement.jsx`)**:
  - 최고 관리자가 신규 등록 모달을 통해 영업사원을 등록할 때와 하단 폼을 통해 영업사원 계정을 편집할 때 환급 계좌정보를 입력/수정할 수 있도록 기능 적용.
- **내 정보 화면 (`busTaams_admin/src/pages/MyInfo.jsx`)**:
  - 로그인된 사용자 본인이 영업사원일 경우 프로필 요약 카드에 등록된 계좌정보(은행 및 계좌번호)를 표시하고, 우측의 개인정보 수정 폼에서도 계좌정보를 직접 수정 및 동기화할 수 있도록 지원.
