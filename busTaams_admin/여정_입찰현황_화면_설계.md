# 여정/입찰현황 화면 설계서

본 문서는 관리자 페이지의 **여정/입찰현황** 화면에 대한 명세 및 백업 문서입니다.

> **최초 작성일**: 2026-05-21  
> **최종 수정일**: 2026-05-21  
> **상태**: 활성(Active)  
> **관련 문서**: [여정/입찰 정산 화면 설계서](./여정_입찰_정산_화면_설계.md) — 정산·매출 조회는 별도 메뉴로 분리됨

---

## 1. 화면 개요
- **메뉴명**: 여정/입찰현황
- **목적**: 플랫폼에 등록된 모든 여행 요청 건의 정보, 버스 기사들의 입찰/매칭 현황, 관련 민원(문의, 취소 페널티, SMS 이력)을 한눈에 모니터링하여 고객 관리 및 문제 해결을 지원합니다.
- **주요 대상 테이블**: `TB_AUCTION_REQ`, `TB_USER`, `TB_BUS_RESERVATION`, `TB_BUS_DRIVER_VEHICLE`, `TB_SMS_LOG`, `TB_INQUIRY`, `TB_USER_CANCEL_MANAGE`

---

## 2. 화면 구성 및 UI 설계

### 2.1. 메인 목록 화면
- **검색 조건**:
  - **출발일자 기간**: `출발일자(From)` ~ `출발일자(To)` 날짜 범위 조회 (`TB_AUCTION_REQ.START_DT` 기준)
  - 조건 선택: 전체 통합 검색, 여행 제목, 예약자명
  - 검색어 입력 및 초기화 기능 (날짜 조건도 함께 초기화)
- **목록 테이블 컬럼**:
  - **예약 고객**: 여행자 이름 및 프로필 아이콘
  - **여행 제목**: 여정의 제목
  - **출발지 / 목적지**: 간략 주소 표시
  - **여행 일정**: 출발 및 도착 일시
  - **요청 금액**: 여행자가 제시하거나 매칭된 금액
  - **결제 상태**: 결제대기(0), 결제요청(1), 결제완료(2) 상태를 색상 배지로 표시
  - **진행 상태**: 대기(AUCTION), 입찰중(BIDDING), 확정(CONFIRM), 완료(DONE), 취소(CANCEL) 상태를 배지로 표시
  - **등록 일시**: 요청 등록 시각
- **동작**:
  - 테이블의 특정 행(Row)을 클릭하면 해당 여정의 상세 모달(Slide-over)이 노출됩니다.

### 2.2. 상세 정보 모달 (Slide-over)
상세 정보 모달은 크게 5가지 섹션으로 나누어 관련 정보를 탭 또는 그리드 형태로 한눈에 보여줍니다.

1. **여정 기본 정보 (Trip Details)**
   - 예약 고객의 상세 정보 (이름, ID, 휴대폰번호)
   - 출발/목적지 전체 주소 및 여정 상세 (출발/도착 일시, 승객 수, 요청 가격)
2. **입찰 현황 (Bidding List)**
   - 해당 여정에 응찰한 버스 기사 목록
   - 기사 정보 (이름, 휴대폰번호), 차량 정보 (차량번호, 모델명, 주행거리)
   - 입찰 제시 가격 및 현재 입찰 상태 (CONFIRM, BIDDING, CANCEL 등)
3. **민원 문의 이력 (Customer Inquiries)**
   - 해당 여행자가 접수한 최근 5건의 문의사항 (`TB_INQUIRY` 연계)
   - 카테고리, 제목, 문의 내용, 답변 여부 및 답변 본문 표시
4. **취소 페널티 현황 (Traveler Penalties)**
   - 해당 여행자의 누적 취소 횟수 (`TB_USER_CANCEL_MANAGE` 연계)
   - 거래 제한 상태 및 제한 시작/종료 일시 조회
5. **알림 발송 이력 (SMS Send Logs)**
   - 이 예약 요청(`REQ_ID`)과 관련하여 발송된 SMS 알림 내역 (`TB_SMS_LOG` 연계)
   - 발송 목적, 수신 번호, 메시지 내용, 발송 상태 (성공/실패), 발송 시각

## 3. 백엔드 API 명세

### 3.1. 여정 목록 조회 API
- **Endpoint**: `GET /api/admin/trips`
- **Query Parameters**:
  - `startDtFrom`: 출발일자 시작 (`YYYY-MM-DD`) — 미입력 시 필터 미적용
  - `startDtTo`: 출발일자 종료 (`YYYY-MM-DD`) — 미입력 시 필터 미적용
  - `searchType`: `'all' | 'tripTitle' | 'travelerName'`
  - `searchKeyword`: 검색어 문자열
- **필터 조합**: 날짜 조건과 키워드 조건은 `AND`로 결합하여 복합 조회 가능
- **Response**: 여정 목록 배열 (JSON)
