# 아이디/비밀번호 찾기 기능 요건 정의서

## 1. 개요
로그인 화면에서 사용자가 자신의 계정 정보를 분실했을 때, 본인 확인(이름, 휴대폰 번호 등)을 통해 아이디를 확인하거나 비밀번호를 안전하게 재설정할 수 있도록 함.

## 2. 상세 요건

### 2.1 아이디 찾기 (Find ID)
- **트리거**: 로그인 모달 하단의 'ID/비밀번호 찾기' 링크 클릭 시 별도 모달 또는 탭으로 노출.
- **입력 항목**:
  - 이름 (User Name)
  - 휴대폰 번호 (Phone Number)
- **동작**:
  - [찾기] 버튼 클릭 시 서버 API 호출.
  - 정보가 일치하는 계정이 존재하면, 입력 폼 아래에 **"회원님의 아이디는 [아이디] 입니다."** 라는 문구 노출.
  - 일치하는 정보가 없으면 에러 메시지 노출.

### 2.2 비밀번호 찾기 및 재설정 (Find/Reset Password)
- **입력 항목**:
  - 아이디 (Login ID)
  - 이름 (User Name) - *추가 보안을 위해 포함 권장*
  - 휴대폰 번호 (Phone Number)
  - 이메일 (Email)
- **동작**:
  - [본인 확인] 버튼 클릭 시 서버 API 호출.
  - 정보가 모두 일치하면, 동일 화면 내에 **비밀번호 변경 섹션**이 나타남.
- **비밀번호 변경 섹션**:
  - 입력 항목: 새 비밀번호, 새 비밀번호 확인
  - [비밀번호 변경] 버튼 클릭 시 서버 DB의 암호화된 비밀번호를 업데이트.
  - 변경 성공 시 "비밀번호가 변경되었습니다. 다시 로그인해 주세요." 안내 후 로그인 창으로 유도.

## 3. 기술 설계 (예정)

### 3.1 백엔드 API
- `POST /api/auth/find-id`: 이름/전화번호로 유저 검색
- `POST /api/auth/verify-for-password`: ID/전화번호/이메일 일치 여부 확인
- `POST /api/auth/reset-password`: 본인 확인 완료 후 새 비밀번호 저장 (암호화 필수)

### 3.2 프론트엔드 컴포넌트
- `FindAccountModal.jsx`: 탭 형식(아이디 찾기 / 비밀번호 찾기)으로 구성된 통합 모달 컴포넌트.
