# 기사 상세 정보 및 리뷰 모달 (Driver Detail Modal)

이 화면은 여행자가 예약을 확정하기 전, 입찰에 참여한 기사님의 신뢰도를 검증하기 위해 제공되는 상세 정보 화면입니다. 기사님의 기본 프로필과 함께 다른 여행자들이 남긴 실제 별점 및 리뷰 내용을 투명하게 보여줍니다.

## 1. 화면 개요
- **목적**: 기사님의 자격 및 과거 서비스 이력을 보여줌으로써 여행자의 의사결정을 돕고 서비스 신뢰도를 높임.
- **진입 경로**: 견적 현황 리스트 > [기사 상세 정보] 버튼 클릭.
- **형태**: 현재 화면 위에 팝업되는 모달(Modal) 방식 (백드롭 처리).

## 2. 주요 구성 요소
### 2.1 상단: 프로필 영역
- **기사 사진**: `TB_USER.PROFILE_FILE_ID`와 연결된 원형 프로필 이미지.
- **기사 이름**: `TB_USER.USER_NM` (예: "홍길동 기사님").
- **통계 요약**: `TB_TRIP_REVIEW`에서 계산된 평균 별점 및 총 리뷰 개수 표시.
- **자기소개**: `TB_DRIVER_INFO.BIO_TEXT` (기사님이 직접 작성한 베테랑 경력 등).

### 2.2 하단: 여행자 생생 리뷰
- **리뷰 리스트**: `TB_TRIP_REVIEW` 테이블의 데이터를 최신순으로 정렬.
- **작성자**: 여행자의 익명성 보호를 위해 마스킹 처리 (예: "김* *님").
- **별점**: 5점 만점의 시각적 별점 아이콘 (`renderStars` 함수 활용).
- **리뷰 내용**: 실제 이용 고객의 코멘트.
- **작성일**: 리뷰가 등록된 날짜.

## 3. 데이터 연동 (API)
- **Endpoint**: `GET /api/driver/detail/:driverId`
- **응답 데이터**:
  - `driver`: 이름, 사진, 소개말, 자격증 종류 등.
  - `reviews`: 별점, 내용, 작성자 이름, 등록일의 배열.

## 4. UI/UX 포인트 (Aesthetics)
- **프리미엄 디자인**: 상단 그라데이션 배경과 `backdrop-blur` 효과를 사용하여 세련된 느낌 전달.
- **반응형 스크롤**: 리뷰 내용이 많을 경우 하단 영역만 독립적으로 스크롤되도록 설계.
- **인터렉션**: 모달 오픈 시 `animate-in` 효과로 부드럽게 등장.
